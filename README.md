# 冷凍機械責任者 試験対策アプリ

第三種・第二種冷凍機械責任者試験（法令・保安管理技術・学識）の学習用アプリです。
サーバー不要の単一HTMLファイルで、スマートフォン・PCのブラウザで動作します。

## 使い方

`index.html` をブラウザで開くだけです。GitHub Pages に置く場合はリポジトリの
Settings → Pages で公開すると、`https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。

- 級切替（三冷／二冷）は画面右上
- 模擬試験：本試験と同じ問数・制限時間で論点ごとに1問ずつ出題し、最後に採点
- 分野別ドリル：論点を選んで1問ずつ解き、その場で正誤と解説を確認
- 復習：前回間違えた問題をもう一度
- 成績：模擬試験の履歴と論点別の正答率

成績はブラウザの localStorage に保存されます（端末・URLごとに別管理）。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 生成物。配布・公開するのはこのファイルだけ |
| `shell.html` | アプリ本体（HTML/CSS/JS）。`/*__DATA__*/` に問題データが埋め込まれる |
| `questions.json` | 論点表と問題データ（三冷：法令40問・保安30問。法令は二冷と共用） |
| `questions2.json` | 二冷の追加問題（保安20問・学識理論16問・法令事例形式12問）と事例文 |
| `questions3.json` | 法令の追加問題（20論点×3問＝60問、三冷・二冷共用） |
| `questions4.json` | 三冷 保安管理技術の追加問題（15論点×3問＝45問） |
| `questions5.json` | 二冷の追加問題（保安10論点×3問＝30問、学識8論点×3問＝24問） |
| `build.py` | 検証・選択肢生成・結合。`python3 build.py` で `index.html` を再生成 |

## 問題データの形式

```json
{
  "id": "L01-1",
  "levels": ["3", "2"],
  "subject": "law",
  "slot": 1,
  "case": "A",
  "stem": "次のイ、ロ、ハの記述のうち、正しいものはどれか。",
  "statements": [
    {"k": "イ", "t": "記述文", "ok": true,  "why": "解説"},
    {"k": "ロ", "t": "記述文", "ok": false, "why": "解説"},
    {"k": "ハ", "t": "記述文", "ok": true,  "why": "解説"}
  ]
}
```

- `levels`：出題する級。`"3"` 三冷、`"2"` 二冷
- `subject`：`law`（法令）、`safety`（保安管理技術）、`gakushiki`（学識）
- `slot`：本試験の出題順（問1〜）に対応する論点番号。論点名は `topics` に定義
- `case`：任意。`cases` に定義した事例文のキー（二冷法令の事例形式用）
- `statements`：記述3つ（法令）又は4つ（保安・学識）。`ok` が正誤、`why` が解説
- 選択肢 (1)〜(5) は `build.py` が `ok` の組合せから自動生成します（ID ごとに固定）。
  正解と一致する選択肢が1つだけになることを検証します

二冷学識の問1・問2（p-h線図の計算、ピストン押しのけ量とCOPの計算）は
`shell.html` 内のジェネレータが出題ごとに数値を生成します。

## 問題を追加・修正するとき

1. `questions.json` 又は `questions2.json` を編集（記述内の二重引用符は「」を使う）
2. `python3 build.py` を実行
3. エラーが出なければ `index.html` が更新されます

## 出題の根拠と注意

- 令和7年度公表問題（高圧ガス保安協会）の論点構成と出題形式に基づいて作成した
  オリジナル問題です。公表問題の複製ではありません
- 法令は令和7年4月1日現在の内容を基準にしています。法改正時は該当問題を見直してください
- 正誤判定は条文・教科書の知識に基づいて作成しています。配布前に法規集等で確認することを推奨します

## 二冷の法令論点について

二冷の法令は問1〜8の出題順が三冷と異なり（問4 第二種製造者、問7 貯蔵、問8 冷凍能力）、問9〜14は事例A、問15〜20は事例Bの設定文つきで出題される（令和7年度公表問題に基づく）。三冷・二冷共用の法令問題には `build.py` の `LAW_SLOT_3_TO_2` で二冷用の論点番号 `slot2` が自動付与され、アプリは二冷選択時に `slot2` を使う。設定文のない一般問題には論点名の「事例A：」「事例B：」を表示しない。
